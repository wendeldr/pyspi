Bounded EEG workflow baseline: completed

39 retained configurations; three initial 0.5-second windows per case.
The whole continuous recording is loaded and prepared before those windows.
Each case ran once in a fresh serial process with numerical thread limits of 1.
Cases ran in order 50, 118, 249. OS caches were not cleared.

All 351 metric/window attempts succeeded. All saved values matched writer
inputs bit exactly. Channel/window order, availability and expected NaN
diagonals passed verification. No infinities or unexpected NaNs were found.
Accessed source EDF/legacy-metadata sizes and mtimes are unchanged.
Package code and dependency files are unchanged.

Calculation dominates total time for this selected workload. Larger output
batches reduced write time and file count. The 249-channel process peaked at
9.35 GiB; memory must be measured when choosing future concurrency.

This is not a full-185 or full-patient benchmark. Scientific correctness is
not established by successful calculation or exact storage. No full-patient
or cohort runtime projection is made. See METHOD.txt for scope and repeat use.
